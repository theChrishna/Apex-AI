# Figures

PNG, 200 dpi, 13.33 x 7.5 in (16:9 slide size), light and dark variants of each. Generated by `figures/make_figures.py` (needs matplotlib; it was run from a scratch venv, the project `.venv` does not have matplotlib):

```bash
python figures/make_figures.py
```

The script only reads the data files. Numbers are copied from the files as written; nothing is recomputed or rounded.

| Figure | Source | Caveats |
|---|---|---|
| `fig_a_shadow_risk_{light,dark}.png`: top-node risk per 15 s cycle, rule and GNN, across the shadow run | `shadow_run/audit_rule.jsonl`, `shadow_run/audit_gnn.jsonl` (SCORED events, 2026-10-26 05:48:25Z to 07:02:27Z); fault windows from `shadow_run/fault_log_shadow.jsonl` (shaded); first REROUTE / ACTION_BLOCKED / SUPPRESSED_VICTIM inside each window (vertical line) from the same audit files | A SCORED event holds only the **top** node and its risk, not all four nodes, so this is top-node risk, not per-node risk. Dry-run: nothing was applied, so no recovery is visible. The two scorers score on different scales (rule is `(in_lat - out_lat)/100 ms` clipped to 1; GNN is a seed-averaged probability), so compare timing, not heights. The line is cut at the end of the scheduled run; audit lines after it are not plotted. |
| `fig_b_detection_time_{light,dark}.png`: seconds from fault start to the first decision event, per fault and scorer | `shadow_run/results_shadow.md`, table "Fault windows" (column "s after start"), written by `shadow_run/compare.py` | 4 faults, one run, one testbed. Rule and GNN are identical in every window. Times sit on 15 s controller cycles and look set by the persistence rule, not by the scorer (my reading, not tested separately). Bars mix REROUTE (ratings) and ACTION_BLOCKED (details, reviews): "detection" means the first decision event, not a recovery. |
| `fig_c_loeo_ap_{light,dark}.png`: AP per leave-one-episode-out fold for p95 baseline, culprit rule, no-graph MLP and GNN | `results_controls.md`, Control 3, table "Average Precision" | **Distinct-threshold AP** (the correct method: the p95 baseline has many tied zero scores and the older trapezoidal numbers in `results_loeo.md` depend on sort order among ties; trapezoidal means are GNN 0.923 and baseline 0.898). "Culprit rule" is the `CS(raw)` column, the raw-millisecond rule the control plane actually runs; the `CS(log1p)` column (mean 0.935) is in the file but not plotted. GNN column is the file's "excl-collapse mean" (one collapsed seed in fold 3 is excluded; counting it as 0 lowers the GNN mean, see `results_loeo.md`). 8 episodes, 2 of them legacy episodes A and B, one testbed. The GNN is not better than the simple scorers; the MLP's 0.983 mean is the highest. |
| `fig_d_pipeline_{light,dark}.png`: control-plane pipeline and probe/release loop | `meshheal_controlplane/controlplane/controller.py`, `scorer.py`, `config.py`, `README_controlplane.md` | A schematic, no measured data. Values shown come from `Config`: 15 s loop, 500 ms scorer budget, act threshold 0.85, persistence 3 of last 4 plus the current cycle, snapshot staleness 45 s, cooldown 120 s, probe 90 s at 70/15/15 (`probe_share` 30), release below 0.60 with at least 0.05 req/s. The probe split changed from 90/5/5 to 70/15/15 after the shadow run; the closed-loop RELEASE has not been seen live yet. |
